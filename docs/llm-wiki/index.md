# LLM Wiki Skill：让知识持续生长

[返回专题首页](/llm-wiki/)

LLM Wiki Skill 帮助 Agent 初始化、采集、查询、检查和维护一个基于 Markdown 的知识库。它把原始来源、可复用知识与结构规则分开保存，让一次整理的结果可以支持之后的阅读和提问。

当前文档对应公开版本 **v1.0.0**。GitHub 仓库是 Skill、模板、脚本和版本发布的**唯一可信源码**；本站只解释原理与操作，不镜像安装文件。

## 从这里开始

- [理解工作原理](/llm-wiki/principles)：Raw / Wiki / Schema 为什么能形成知识复利。
- [从零构建知识库](/llm-wiki/build)：完成一次来源采集、互链与质量检查。
- [安装 LLM Wiki Skill](/llm-wiki/install)：验证下载文件并安装到 Codex。

## 它适合什么任务

- 把文章、论文或访谈整理成机制页，而不是堆积孤立摘要。
- 沿索引、Hub 和页面链接查询已有知识，并明确指出缺口。
- 检查元数据、断链、孤立页、冲突和敏感信息。
- 在不重写全部内容的前提下增量维护知识网络。
