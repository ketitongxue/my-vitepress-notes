# 产品验证循环

产品验证的目标不是证明想法正确，而是尽快发现最关键的错误假设。

## 最小闭环

1. 写出一个可证伪的用户假设。
2. 构建能观察关键行为的最小版本。
3. 根据真实行为保留、修改或停止方案。
