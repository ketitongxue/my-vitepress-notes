# Site Design Refinement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing VitePress site lead with its AI knowledge base and Q&A, turn both generated knowledge indexes into scannable hubs, reduce sidebar density, and clarify that Q&A remains AI-Wiki-only.

**Architecture:** Keep the default VitePress theme and existing Markdown publication pipeline. Extend collection metadata and the deterministic index generator so future Wiki syncs preserve the new hub structure, then add narrow theme/config and Q&A presentation changes without changing Worker APIs or retrieval.

**Tech Stack:** VitePress 1.6.4, Vue 3 SFC, Markdown, Node.js 22 tests, Cloudflare Worker unchanged.

## Global Constraints

- Q&A remains limited to the AI knowledge base; Finance is not added to the QA index or Worker.
- Published routes, manifests, page counts, rate limits, quotas, secrets, and Worker behavior do not change.
- The site remains force-dark and keeps the current palette and default VitePress theme.
- Knowledge index design must be generated by `scripts/wiki-publish/finalize.mjs`, not maintained only by manual edits.
- Navigation and disclosure controls must remain keyboard accessible; hover cannot be the only interaction.
- `docs/superpowers/**` remains excluded from the public build.
