# 网站设计优化设计说明

日期：2026-07-10

## 目标

在保留现有 VitePress 深色视觉、知识发布流程、Wiki 问答 Worker 和限额策略的前提下，修复设计审查发现的首页信息重点、知识库可发现性、侧边栏密度、问答范围表达和移动端导航问题。

## 范围

本次包含：

- 首页主标题断行、首屏行动入口和最近更新内容。
- 顶部知识库菜单命名与桌面悬浮行为。
- AI 知识库和金融知识库入口页的信息架构。
- 两个知识库侧边栏的默认折叠状态，以及金融实体的短标题。
- 问答页的检索范围说明、空状态高度和 AI 知识库入口。
- 桌面端与 390px 手机端视觉复核。

本次不包含：

- 金融知识库检索或金融问答。
- Worker、DeepSeek、检索索引、配额和限速逻辑修改。
- 全新 VitePress 主题或路由重构。
- 知识文章正文内容重写。

## 设计方案

采用在现有 VitePress 默认主题上做轻量增强的方案。继续使用 Markdown 首页、主题配置和自定义 CSS；知识库入口页保持 Markdown 作为发布脚本的稳定输出格式，通过结构化 HTML 容器和 CSS 改善首屏，不引入新的运行时依赖。

### 首页

- 将主标题调整为稳定的两行或合理换行，桌面端不得出现单个“造”字独占一行。
- 主行动按钮为“浏览知识库”，链接 `/wiki/`。
- 次行动按钮为“向知识库提问”，链接 `/ask/`。
- 三张主题卡片保持不变。
- “最近生长”改为展示知识库最近更新入口，至少同时包含 AI 知识库和金融知识库，日期不得早于各入口页当前同步日期。
- 保留现有颜色、圆角、字号层级和整体留白节奏。

### 顶部导航

- 一级菜单名称保持“知识库”。
- 两个二级入口统一为“AI 知识库”和“金融知识库”。
- 桌面端允许鼠标悬浮或点击打开菜单；键盘和移动端继续使用按钮展开，不移除默认焦点与 `aria-expanded` 行为。

### 知识库入口页

- AI 页面标题统一为“AI 知识库”，不再混用“AI Wiki”和“LLM Wiki 中文知识库”。
- 页面首屏依次包含简介、页面数量、最近同步日期、精选入口和分类概览。
- 精选入口使用现有代表性文章，不新增虚构内容。
- 全部文章仍按“实体 / 概念 / 对比分析”保留，放在原生 `<details>` 折叠区中，保证无 JavaScript时仍可访问。
- 发布清单、公开路由和文章数量必须保持不变。

### 侧边栏

- AI 和金融知识库的“实体 / 概念 / 对比分析”默认全部折叠，减少初次进入时的视觉噪声。
- 金融实体侧边栏使用中文短名：本杰明·格雷厄姆、爱德华·索普、乔治·索罗斯、詹姆斯·西蒙斯与大奖章基金、LTCM 崩塌、沃伦·巴菲特。
- 页面正文中的中英文完整标题保持不变。
- 侧边栏必须继续包含各自 manifest 中的全部公开页面，链接不得变化或重复。

### 问答页

- 明确写出“回答仅基于 AI 知识库”，并说明附带站内引用。
- 增加“浏览 AI 知识库”链接。
- 示例问题继续只覆盖 AI、产品和工程内容。
- 空对话区域在桌面端降低最小高度，使输入框更靠近示例问题；出现回答后仍允许滚动。
- 现有发送、停止、清空、会话存储、流式响应和错误处理行为保持不变。

## 可访问性

- 保留跳转正文链接、语义导航、标题层级、表单标签和状态播报。
- 新增链接和折叠控件必须可由键盘访问。
- 悬浮菜单不能成为唯一打开方式。
- 不降低现有正文与辅助文字对比度；焦点状态继续使用品牌色高亮。
- 减少动态效果的系统偏好继续生效。

## 测试与验收

- 配置测试验证统一命名、侧边栏折叠状态、完整 manifest 路由和金融短标题。
- 页面契约测试验证首页 CTA、最近同步日期、知识库首页折叠结构和问答范围说明。
- 样式契约测试验证桌面标题宽度、悬浮菜单、知识库首页布局、问答空状态和移动端规则。
- 完整运行 `npm test`，并要求所有现有 Wiki、Finance、Worker、安全扫描和 VitePress 构建测试通过。
- 在桌面默认视口及 390 × 844 视口检查首页、知识库菜单、两个入口页、文章页和问答页。

## 成功标准

- 桌面首页标题不再产生单字孤行。
- 首屏直接提供知识库和问答入口。
- 两个知识库入口首屏不再呈现几十条平铺链接。
- 侧边栏初始状态更简洁，且所有文章仍可访问。
- 问答页明确只检索 AI 知识库。
- 桌面悬浮、点击、键盘与移动端导航均能访问两个知识库。
- 发布内容、问答后端和限额策略没有行为变化。
